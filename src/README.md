# Problem Solving with TypeScript & OOP

## Assignment Overview

This repository contains solutions to the TypeScript Problem Solving and Object-Oriented Programming assignment based on Modules 1, 2, and 3.

The assignment demonstrates practical implementations of TypeScript fundamentals, advanced types, generics, asynchronous programming, and object-oriented programming concepts.

## Technologies Used

- TypeScript
- JavaScript (ES6+)
- Node.js
- Object-Oriented Programming

## Implemented Problems

1. Optional and Default Parameters
2. Union Types and Type Narrowing
3. Readonly Tuples
4. Generics and Rest Parameters
5. Interfaces and Array Filtering
6. Generic Functions with keyof
7. Classes, Inheritance, and Access Modifiers
8. Promises and Async/Await

## How to Run

Install TypeScript:

```bash
npm install -g typescript
tsc --init
```

Compile the TypeScript code:

```bash
npx tsc
```

The compiled JavaScript file will be generated according to the TypeScript configuration.
